A little notch. A lot going on.

Isle is an independent GNOME Shell extension inspired by the desktop notch concept. It gathers useful daily tools in one compact place, keeping the interface close at hand without turning the desktop into another dashboard.

What it brings together

Music and synced lyrics, focus and water timers, a file and text shelf, to-dos, calendar reminders, wallpaper switching, battery and hardware status.

How it is organized

Focused pages sit on top of shared JavaScript services for playback, timers, storage, and system state. Styling and settings live alongside the GNOME Shell extension code.
