Featured project

Isle: a little notch, a lot going on

An open source GNOME Shell extension

Isle is an independent extension inspired by the desktop notch concept. It gathers useful daily tools in one compact place, keeping the interface close at hand without turning the desktop into another dashboard.

Explore the source code Browse all repositories

What it brings together

Music and synced lyrics, focus and water timers, a file and text shelf, tasks, calendar reminders, wallpaper switching, battery and hardware status.

How it is organized

Focused pages sit on top of shared JavaScript services for playback, timers, storage and system state. Styling and settings live alongside the extension code.

Questions

Frequently asked questions

What do you do?

I am an Odoo developer. I build around business rules, workflows and records so the system fits the way work actually happens.

Which Odoo versions do you work with?

I work across Odoo 15, 16, 18 and 19.

What is Isle?

Isle is an independent GNOME Shell extension inspired by the desktop notch concept. It gathers ten everyday tools in one compact place on the Linux desktop.

What does Isle include?

Music and synced lyrics, focus and water timers, a file and text shelf, tasks, calendar reminders, wallpaper switching, battery status and hardware status.

Is the source code public?

Yes. Isle is a public repository on GitHub, so you can read the code before you try it.

Which technologies do you use?

Odoo and Python for business systems. GJS, JavaScript, CSS and shell scripts for Linux desktop tools. Git throughout.
